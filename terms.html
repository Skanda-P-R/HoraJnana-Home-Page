2. Description of Service

HoraJnana provides specialized astronomical calculation software for Vedic astrological traditions (Panchanga limbs, planetary Hora timings, Vimshottari Dasha systems, and North/South/East Indian Kundali charts). Services are provided across multiple channels:

  • HoraJnana Web App: Static Progressive Web Application accessible via modern web browsers.
  • HoraJnana Android App: Native Android software available on Google Play (Package: com.hora.jnana).
  • Calculation API: Backend computational endpoints providing ephemerides data.
